### De qué se trató el proyecto  
VAX Solutions, una empresa del **sector logístico**, operaba sus procesos de planeación y venta de envíos de manera manual. Esto generaba ineficiencias, errores y una falta de visibilidad que limitaba su crecimiento. La compañía necesitaba una **herramienta robusta** y a medida que centralizara su operación, desde la gestión de clientes y transportistas hasta la creación de rutas y el intercambio de documentos.

---

### Qué problema solucionó  
Se desarrolló un **sistema de administración integral** para optimizar la logística de VAX Solutions. El proyecto se enfocó en crear una plataforma que no solo automatizara tareas, sino que también proporcionara un control total sobre cada etapa del envío.

- **Gestión Centralizada:** Se implementó un sistema que permite registrar y gestionar clientes, transportistas y la totalidad de la flota.

- **Rutas Inteligentes:** La funcionalidad central fue la creación de rutas. La aplicación fue diseñada para ligar el cliente con el tipo de carga y asignar automáticamente el transportista ideal para el viaje.

- **Documentación Automatizada:** Se creó un subsistema dedicado a facilitar el intercambio de documentos necesarios entre los transportistas y VAX Solutions, eliminando cuellos de botella y acelerando los procesos.

- **Visibilidad en Tiempo Real:** Se integró la API de Google Maps para visualizar las rutas de forma interactiva en un mapa, con puntos de origen, destino y paradas clave como cruces fronterizos, proporcionando tiempos de viaje estimados y mejorando la planificación.

- **Tecnología Robusta:** El proyecto fue construido con PHP, JavaScript, HTML y CSS puros, y desplegado en Google Cloud Platform (GCP), utilizando servicios clave como Google Cloud Storage para la gestión de archivos.

---

### El impacto  
El sistema transformó la operación de VAX Solutions. Al automatizar sus procesos, la empresa pudo reducir errores, optimizar sus rutas y tomar decisiones más informadas. Esto se tradujo en una mayor eficiencia operativa y una mejor experiencia para sus clientes, consolidando a VAX Solutions como un líder en su industria.
